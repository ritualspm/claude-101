# Experiment Read: June Checkout Test (T-2026-0612)

**Analyst:** Marco · **Read date:** 2026-06-17 · **Status:** Interim (Android only)

## What we tested
Moving the reorder card to the top of the home screen vs. current position (control).

## Setup
- Market: QuickMart DE, Android
- Duration so far: 6 days
- Users: ~180k control / ~180k variant (all data aggregated, no individual customers)

## Results so far
- Checkout conversion: **+1.9%** (variant vs control) — significant
- Average order value: **flat** (-0.2%, not significant) — guardrail holds
- Reorder card tap-through: **+22%**

## Caveats
- iOS not yet included — do not generalize.
- One weekend included, which skews basket size upward. Need a full second week.
- Payment latency incident on 2026-06-15 evening may have depressed variant slightly.

## Recommendation
Keep running one more week on Android. Do NOT expand to iOS yet. Revisit with Priya next Wed.
