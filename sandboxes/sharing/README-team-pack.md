# Squad Toolkit — drop-in pack for new PMs (DEMO / OBVIOUSLY FAKE)

> This is a sample "team pack" for a made-up squad, shown in Lesson 3.8 so you can see
> what a *shareable* set of Claude assets looks like. Fake squad, fake names, no real
> data. A team pack is just a folder of plain-English files a teammate can drop in
> and use on day one — no setup call needed.

## What's in this pack
- `weekly-skill.md` — the `/weekly` update recipe (well-packaged version)
- `weekly-skill-BEFORE.md` — the same skill *before* it was made shareable (spot the gaps)
- `vp-persona.md` — the "Priya, VP Product" reviewer persona
- `team-rules.md` — the shared CLAUDE.md rules everyone on the squad uses

## How a new teammate uses this (the whole story on one page)
1. Copy this folder into their own Claude workspace.
2. Tell Claude: *"Install `weekly-skill.md` as a skill called `/weekly`."*
3. Tell Claude: *"Use `team-rules.md` as my rules for this project."*
4. That's it — they now get the same weekly update, in the same shape, with the same
   guardrails as the rest of the squad.

## Ground rules for anything in this pack (non-negotiable)
- **Draft, never send.** Nothing here posts to Slack, email, or Jira on its own.
- **Read-only on real data.** Skills read and summarize; they never write to real systems.
- **No customer PII or payment data.** Never bake a real name, email, phone, or card
  number into a shared file — it would then travel to everyone who uses the pack.
- **Sonnet by default.** These are everyday rituals, not hard problems.
