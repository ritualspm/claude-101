# /weekly — Weekly Team Update (EXAMPLE SKILL — obviously fake)

> This is a sample skill file, shown in Lesson 3.1 so you can see what one looks like
> before you write your own. Everything below is plain English — no code. A skill is just
> a saved set of instructions Claude follows when you type its command.

## What this skill does
When I type `/weekly`, produce a **draft** Monday team update in my standard format.
Read the sources listed below, pull out what changed, and write it up. Stop at a draft —
never post anything.

## Where to look
- The docs in the folder `sandboxes/skills/team-sources/`
- (Real version would also read my #squad-checkout Slack channel — read-only)

## Format — always use exactly this shape
**Squad Weekly — [week of DATE]**

**1. Shipped this week** — 2–4 bullets, each with the impact if we know it.
**2. In progress** — what's moving, and any blocker, one line each.
**3. Needs a decision** — anything waiting on a person; name who.
**4. Metric watch** — one line on the number we're tracking.

## Rules
- Keep it under 200 words. Scannable. Bold the section headers.
- Plain, direct tone — no corporate filler.
- If a source is missing or unclear, say so in one line rather than guessing.
- **Draft only — never send or post.** I approve before anything goes out.
- Never include customer names, emails, phone numbers, or payment data.
