# L1 — The Three Doors (and why Cowork is home)

**Course:** Using Claude · **Level 1 — Get Oriented** | ~20 min
**Part times:** Concepts ~10 min | Exercise ~6 min | Decision Point ~4 min
**Previous lesson:** None — first lesson.

**WHO THE LEARNER IS (load-bearing):** A product person, likely brand new to Claude and possibly to the terminal. Teach through analogy and their own screen. Most are taking this *inside Cowork right now* — use that constantly. Never show code. Anchor everything to real PM tasks.

**HOW TO RUN THE CHECKS:** Each concept ends with a multiple-choice check — clickable cards (`AskUserQuestion`) if available, else A/B/C. Correct option marked ✓ (never shown). One question per turn; always explain the outcome before the next concept.

---

## Part 1: The Concepts

### Concept 1 — Claude is one brain, with three doors
This is the mental model that prevents all confusion later. Claude Code is **not three different products** — it's **one engine** (it knows your files, your saved context, your rules, your connected tools). There are just **three doors** into that same brain:

- **Chat** — a quick conversation, like messaging a smart colleague. No access to your files. Great for a fast question or a quick draft.
- **Cowork** — a **visual workspace**: Claude can see your files, do multi-step work, and you watch it and approve as it goes. It's a desktop app — **no terminal needed.** This is home base for most product people.
- **Code** — the raw **terminal** version (you type `claude` in a black window). Same engine, for people who live in the terminal.

Same brain behind all three. You pick the door that fits the moment.

**Check** (present the options in random order; ✓ = correct, never reveal it): *A teammate says: "I'll use Cowork for real work and Chat for quick questions — they're basically two different AIs, so I'll set each up separately." What's the best correction?*
- Right — treat them as two separate AIs and set each up on its own.
- They're three doors into the *same* Claude — one brain, so your setup carries across all of them. ✓
- Chat is the real AI; Cowork is just a file browser sitting on top of it.

### Concept 2 — Cowork is the visual workspace (your home base)
Cowork is where a PM gets the most, with the least friction. What makes it powerful:

- **Projects** — you point Claude at a **folder** on your computer, and it can read everything inside (docs, notes, data). That folder becomes a workspace it understands.
- **Tasks** — each piece of work is a **Task**: one focused conversation with a goal ("summarize these 10 docs", "prep my Monday review"). You can have many.
- It **does things, not just talks** — runs multi-step work, uses your connected tools (Slack, Confluence), asks you clickable questions (like the ones in this lesson), and can even work in the background.

You're using it *right now* — that's the point. The course lives in Cowork so you learn it by using it.

**Check** (shuffle order; ✓ = correct): *You want Claude to work across 15 documents for an initiative. In Cowork, what's the smartest first move?*
- Create 15 separate tasks — one per document — so nothing gets mixed up.
- Paste all 15 documents into a single message so it sees everything at once.
- Point a Project at the folder those 15 docs live in, so Claude can read them all. ✓

### Concept 3 — Your setup follows you across all three doors
Here's why the "one brain" idea matters practically: anything you set up — your rules, the context Claude remembers about you, a shortcut you create — **works no matter which door you enter through.** Set it up once in Cowork; it's there in the terminal too, and vice versa. (You'll build that setup in Level 2.)

**Check** (shuffle order; ✓ = correct): *You spent 10 minutes in the terminal (Code) teaching Claude your team and your tone. Tomorrow you open Cowork instead. What happens to that setup?*
- It's tied to the window you created it in — you'd have to set it up again in Cowork.
- It's still there — same Claude behind every door, so your setup follows you. ✓
- It only applied on the day you created it, so it's already expired.

### Concept 4 — Which door, when
A simple rule of thumb:
- **Quick question, no files involved?** → **Chat.**
- **Real work with your docs/tools, and you want to see it happen?** → **Cowork.** (Most of your day.)
- **You already live in the terminal / want raw speed?** → **Code.**

**Check** (shuffle order; ✓ = correct): *You need a quick two-line reword of a Slack message — nothing else, no files involved. Which door is the efficient choice?*
- Cowork — always use Cowork so it has your full context.
- Code — the terminal is the fastest option for everything.
- Chat — it's a quick, file-free ask; no need for the full workspace. ✓

## Part 2: Exercise — Look at your own screen

Real orientation. The learner is in Cowork — have them look.

### Step 1 — Find your bearings (open-ended, short)
Ask: "Look at the left sidebar of your Cowork window. You'll see things like **New task**, **Projects**, **Artifacts**. In your own words — where do you think you'd go to start a fresh piece of work, and where would you go to see the folders Claude is working with?" Validate: **New task** starts fresh work; **Projects** is where folder-workspaces live. Confirm gently, correct if needed.

### Step 2 — Name the door you're in (open-ended, short)
Ask: "Right now, are you in Chat, Cowork, or Code — and how can you tell?" (They're in Cowork — the visual workspace with the sidebar, tasks, and clickable options like these.) Affirm, and point out: the fact that these checks appeared as *clickable buttons* is a Cowork thing — that's the visual workspace at work.

## Part 3: PM Decision Point (open-ended, written)

Frame it: *"You now know the three doors. Write me two quick lines: (1) which door will be your daily home base, and why — and (2) name one specific task where you'd deliberately use a different door instead."*

Max 2 prompts. Evaluate against `scoring-rubrics.md`. The point isn't a 'right' answer — it's that they can match a door to a real way of working, and justify it.
